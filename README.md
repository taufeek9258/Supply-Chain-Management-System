# Supply Chain Management System

## Project Overview
The Supply Chain Management System is an analytics-based project designed to present supply chain data through visual dashboards and reports.

## Project Contents
- Supply Chain Analytics Dataset (Excel)
- Dashboard Screenshots
- Data Visualization and Analytics

## Project Objectives
- Analyze supply chain data.
- Present information through visual dashboards.
- Understand business and operational trends.
- Support data-driven decision-making.
